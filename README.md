# নকশাপথ (Nokshapoth) - সেলিং ল্যান্ডিং পেজ

এই প্রজেক্টটি **নকশাপথ (nokshapoth.com)**-এর একটি ডেডিকেটেড সাবডোমেইন (যেমন: `offer.nokshapoth.com` বা `deal.nokshapoth.com`)-এ হোস্ট করার জন্য বিশেষভাবে তৈরি করা একটি আল্ট্রা-ফাস্ট, হাই-কনভার্টিং সেলস ল্যান্ডিং পেজ।

## 🚀 cPanel / LiteSpeed হোস্টিংয়ে ডিপ্লয়মেন্ট গাইড

### ধাপ ১: সাবডোমেইন তৈরি
1. আপনার cPanel-এ লগইন করুন।
2. **Domains** > **Subdomains**-এ গিয়ে একটি সাবডোমেইন তৈরি করুন (যেমন: `offer.nokshapoth.com`)।
3. এর রুট ফোল্ডার সাধারণত `public_html/offer` হবে।

### ধাপ ২: ফাইল আপলোড
1. এই `Nokshapoth` ফোল্ডারের ভেতরের সব ফাইল জিপ (ZIP) করে cPanel File Manager-এ উক্ত সাবডোমেইনের ফোল্ডারে আপলোড করে এক্সট্র্যাক্ট (Extract) করুন।

### ধাপ ৩: ডাটাবেজ সংযোগ (DB Sync)
1. `config.php` ফাইলটি এডিটরে খুলুন।
2. মূল ওয়েবসাইটের ডাটাবেজ ইউজার, পাসওয়ার্ড ও ডাটাবেজের নাম বসিয়ে দিন:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_USER', 'your_cpanel_db_user');
   define('DB_PASS', 'your_cpanel_db_password');
   define('DB_NAME', 'your_nokshapoth_main_db');
   ```
   > **নোট:** মূল সাইটের অর্ডার টেবিলের কলাম নেম ভিন্ন হলে `api/order.php` ফাইলের `INSERT INTO orders ...` কুয়েরিটি মূল টেবিলের নামের সাথে মিলিয়ে দিন। ডাটাবেজে সাময়িক সংযোগ না থাকলেও প্রতিটি অর্ডার `data/orders/` ফোল্ডারে স্বয়ংক্রিয়ভাবে সেভ থাকবে।

### ধাপ ৪: ফেসবুক সার্ভার-সাইড Conversions API (CAPI) চালু
1. আপনার Meta Events Manager-এ যান।
2. Pixel ID: `1012390691376333` সিলেক্ট করুন।
3. **Settings** ট্যাবে গিয়ে **Conversions API** সেকশনে যান।
4. **"Generate access token"**-এ ক্লিক করে টোকেনটি কপি করুন।
5. `config.php` ফাইলের `FB_CAPI_ACCESS_TOKEN`-এ টোকেনটি পেস্ট করে দিন:
   ```php
   define('FB_CAPI_ACCESS_TOKEN', 'EAABxxxxxxxxxxxxxxxxxxxx');
   ```
6. এখন ক্লায়েন্ট ও সার্ভার উভয় জায়গা থেকেই পারচেজ ট্র্যাক হবে এবং কোনো ডুপ্লিকেট হবে না (অটোমেটিক ডিডুপ্লিকেশন সংযুক্ত)।
